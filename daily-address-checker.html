Daily Address Checker

Upload your daily Shopify order files — every order's address is checked against live postcodes.io, mistakes are fixed automatically or given a clear status, and addresses are corrected automatically: postcode spacing and capitals, ALL CAPS names and towns, and extra spaces are all cleaned up for you, with the corrected address in the export. OpenStreetMap verification now runs automatically on every check — no key needed — and if you add a Serper API key below, every address is also verified against Google Places via Serper inside this tool. Your existing Google Maps API key option for Google Geocoding is still there too — the team never has to open Google Maps. At the end you download a real Excel (.xlsx) file with every field in its own separate column; the download unlocks only when verification has finished. No CSV export, no merged columns. The tool works on any computer and in any browser — no Muse account and nothing to install; just open the link and work.

Every value goes into its own column — Order always in A, Brand in B, Customer in C, Value in D, and so on through to N. Nothing is combined or merged into a single column. Column J is filled only when a live check verifies the address; column K holds the automatically corrected address, together with exactly what was changed, whenever anything was corrected or the address could not be verified; and column L says where the result came from.

Status rules — clear and fixed

OK
Ready to send. The postcode is verified live, and the house number, street and town are all present and already correct.
FIX
Fixed automatically. Postcode spacing or letter case, ALL CAPS names or towns, extra spaces — corrected for you, and the cleaned result is the address in column J or K. Ready to send.
CONFIRM
Ask the customer. The house number is missing, or the town does not match the postcode's area. Confirm before sending.
HOLD
Do not send. The postcode is missing, invalid, or not found on postcodes.io — or the street itself is missing. Get the address corrected first.
ROYAL MAIL PENDING
The address is ready, but today's queue is full. The Royal Mail queue takes only 50 orders a day and orders of £30+ go first — the rest go tomorrow.

Google verification — checked inside this tool, no need to open Google Maps

Paste your Google Maps API key (with the Geocoding API enabled) once. It is stored only in this browser, is sent only to Google itself when an address is verified, and is never included in any export. With a key saved, every checked address is automatically sent to Google Geocoding during the check, and Google's result — its own matched address, match quality and coordinates — appears on each order and in the Excel “Google Verification” sheet.

Verified by GoogleGoogle Geocoding returns the address it holds for the order. A full match is shown as “Google: Verified” with Google's formatted address; a partial match is flagged so the team can look closer.
Not found by GoogleIf Google holds no address for it, the order shows “Google: Not found” — check it against the Issue column (I) before sending.
No key yet?Without a key, Google verification is skipped and every order says “Google: Not checked — API key needed”. The postcodes.io live check, automatic corrections and the Royal Mail queue all keep working as before.

Automatic map checks — OpenStreetMap needs no key, Serper checks Google Places

OpenStreetMap (OSM) — automatic, no key: every checked address is sent to OpenStreetMap Nominatim during the normal check. You do not need to enter anything. Each order shows “OSM: Verified”, “OSM: Partial match” or “OSM: Not found” with the address OSM holds and its coordinates. If OSM cannot be reached (network / CORS), orders are marked “OSM: Not checked” and the rest of the tool — postcodes.io, corrections and the Royal Mail queue — carries on as normal.

Google Places via Serper — your Serper key: paste a Serper API key to verify addresses against Google Places without a Google Maps key. The key is kept only in this tab's memory for this session — it is not saved to localStorage, not written to disk, and never included in any export. It is sent only to google.serper.dev when a check runs. Clear the tab or click Remove and it is gone. If Serper returns an error (wrong key, no credits, rate limit), that error is shown clearly on the orders and here — it does not hide behind a generic “not found”.

OSM: Verified / PartialNominatim found the address. “Verified” means the returned address contains the checked postcode; “Partial match” means a nearby place was found but the postcode did not line up exactly — check column I before sending.
Serper: VerifiedSerper's Google Places returned one or more places for the address. The top place name, address and rating (if Google holds one) appear on the order and in the “Serper Places” sheet.
Not checked / Error“Serper: Not checked — Serper key needed” means no Serper key is in memory for this session. An explicit “Serper: Error — …” means Serper itself replied with an error — read its message (for example invalid key or out of credits) and fix the key.

How the Royal Mail queue works: of the orders ready to send (OK and FIX), those worth £30 or more go first (biggest first), then the rest — the first 50 go today (column M shows “Today #number”); anything beyond that gets the status ROYAL MAIL PENDING and waits in tomorrow's queue. CONFIRM and HOLD orders never join the queue.

Google Verification column: when a Google Maps API key is saved above, this shows Google Geocoding's own result for the order's corrected address — “Verified” with Google's formatted address and coordinates, “Partial match”, or “Not found” — all inside this page, with no need to open Google Maps. Without a key it shows “Not checked — API key needed”, and the postcodes.io result in columns J–L still stands.

OSM Verification column: OpenStreetMap Nominatim runs automatically on every check — no key needed. “OSM: Verified” means the OSM address contains the checked postcode; “Partial match” means OSM found a nearby place without an exact postcode line-up; “Not found” means OSM holds nothing for that query; “Not checked” means OSM could not be reached and the order was left on its postcodes.io result alone.

Google Places (Serper) column: when a Serper key is held in this session, this shows Serper's Google Places result — the top place found, its address and rating where Google provides one. Without a Serper key it shows “Not checked — Serper key needed”. If Serper itself errors (invalid key, no credits, rate limit), the exact Serper message is shown here instead of a fake “not found”.

Automatic corrections: postcode spacing and capital letters are fixed, ALL CAPS customer names and towns are converted to proper case, and extra spaces are removed — automatically, with no manual step. Column K (Suggested Cleaned Address) shows the corrected address together with exactly what was changed, and the corrected address is what appears in the Excel export.
